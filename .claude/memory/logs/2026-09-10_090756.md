## Fixed: interior rejected by the Print Previewer

KDP flagged text outside the margins on every body page. Cause: CSS margin
boxes default to `vertical-align: middle`, so each centred itself in its
margin band instead of sitting near the text block. Measured off the built
PDF: running head **0.193"** from the top trim edge, folio **0.174"** from the
bottom — both inside KDP's 0.25" no-print band.

`tools/bookbuild/styles.py`: running heads pinned to the bottom of the top
band (`vertical-align: bottom`), folio to the top of the bottom band
(`vertical-align: top`). Clearances now 0.380" top / 0.340" bottom, verified
across all 273 pages with `pdftotext -bbox`.

The text block does not move, so the page count stayed 273 — spine width and
cover unaffected, cover PDF byte-identical.

Also fixed `tools/bookbuild/meta.py`: the metadata sheet's upload table still
pointed at `build/` from before editions moved into `build/<lang>/`.

Committed and pushed as `0880ffb`.
