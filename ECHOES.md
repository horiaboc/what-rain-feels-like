# Load-bearing phrases — English source

The novel repeats certain phrases on purpose. The repetition *is* the meaning: a
line planted early is quoted, amended or answered later, and the reader is meant
to recognise it. Change one site and the others silently stop working — an edit
that looks like an improvement where you make it, and breaks a callback three
hundred pages away where nobody is looking.

This file is the list of those phrases. `tools/check_echoes.py en --snapshot`
records how many times each one occurs in each chapter; `--check` reports any
count that has gone **down**. It has no opinion about prose quality. It answers
one question: did an edit over here quietly break a dependency over there.

Every phrase below was verified present in `chapters/` on 2026-09-13, and the
set was audited for near-miss variants; none were found. Matching is literal and
case-sensitive, so a phrase is listed in the exact form it carries in the text.

Lines beginning with `- ` are guarded. Add to them freely; remove only when a
phrase is deliberately retired from the book.
